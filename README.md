# 🧸 ระบบจัดการสต็อก & กำไร-ขาดทุน ร้านของเล่น (Art Toy, Squishy & สำเพ็ง)

ระบบจัดการสต็อกสินค้าแบบ Modern Web App เชื่อมต่อกับ **Google Sheets** โดยตรง (ฟรี 100% ไม่มีค่าบริการรายเดือน) ออกแบบมาเฉพาะสำหรับ**ร้านขายของเล่น, กล่องสุ่ม Art Toy, Squishy นุ่มนิ่ม, และของเล่นกระแสสำเพ็ง**

---

## 🎨 หมวดหมู่สินค้าตัวอย่างที่เซ็ตไว้ให้:
1. **Art Toy / กล่องสุ่ม** (เช่น Baby Three, Crybaby, Labubu, Hirono, Molly)
2. **Squishy / นุ่มนิ่ม** (สกุชชี่จัมโบ้, โมจิสโลว์, กลิ่นหอม)
3. **ของเล่นกระแส / สำเพ็ง** (พวงกุญแจ, สไลม์, ของเล่น TikTok)
4. **ของเล่นเสริมพัฒนาการ / DIY** (เลโก้นาโน, ชุดระบายสี, งานประดิษฐ์)
5. **การ์ด & ของสะสม** (ซองสุ่มการ์ด, การ์ดสะสม)
6. **โมเดล & ฟิกเกอร์**
7. **อื่นๆ**

## 🚀 วิธีอัปเดตข้อมูลสินค้าของเล่นลง Google Sheets

1. เปิด Google Sheet ของคุณ &gt; ไปที่เมนู **ส่วนขยาย (Extensions) &gt; Apps Script**
2. คัดลอกโค้ดจากไฟล์ `google-apps-script/Code.gs` ไปวางแทนที่โค้ดเดิมทั้งหมด แล้วกด **บันทึก (Save)** 💾
3. เลือกฟังก์ชันด้านบนเป็น **`initDatabase`** แล้วกดปุ่ม **"เรียกใช้" (Run)** 1 ครั้ง
   *(ระบบจะล้างข้อมูลเดิมและแทนที่ด้วยหมวดหมู่และสินค้าตัวอย่างของร้านของเล่นให้อัตโนมัติ!)*
4. กด **ทำให้ใช้งานได้ (Deploy) &gt; จัดการการทำให้ใช้งานได้ (Manage deployments)** &gt; กดไอคอนดินสอ ✏️ &gt; เลือก Version เป็น **"เวอร์ชันใหม่" (New version)** แล้วกด **Deploy**
